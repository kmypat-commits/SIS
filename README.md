# MachOpt-6L

**Система поддержки технологической подготовки производства**  
Структурная и параметрическая оптимизация ТП механической обработки на основе иерархической модели и многокритериальной оптимизации Парето.

---

## Быстрый старт

### 1. Backend (Python/FastAPI)

```powershell
cd d:\SIS\backend

# Создать виртуальное окружение (рекомендуется)
python -m venv venv
.\venv\Scripts\Activate.ps1

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер (с авто-перезагрузкой)
uvicorn app.main:app --reload --port 8000
```

Backend доступен на: http://localhost:8000  
Swagger UI: http://localhost:8000/docs

При первом запуске автоматически создаётся SQLite `machopt.db` и заполняется из `data/machopt_mvp_0001.json`.

### 2. Frontend (React/Vite)

```powershell
cd d:\SIS\frontend
npm run dev
```

Frontend доступен на: http://localhost:5173

### 3. Тесты

```powershell
cd d:\SIS\backend
pytest tests/ -v
```

## Сценарий работы

1. **Проект** — просмотр/редактирование мета-данных изделия
2. **Элементы CDE** — раскрываемый список CDE с геометрией и требованиями
3. **База знаний** — станки, оснастка, наладка, инструмент
4. **Оптимизация** → кнопка **▶ Рассчитать** → Парето-фронт → выбор стратегии → экспорт JSON / HTML-отчёт

## Уровни оптимизации (6 уровней)

| Уровень | Объект        | Задача                                           |
|---------|---------------|--------------------------------------------------|
| 1       | Маршрут CDE   | Структура переходов + припуски                   |
| 2       | Маршрут изделия| Кол-во операций, станок/оснастка/базирование    |
| 3       | Наладка        | Определение параметров инструмента/заготовки    |
| 4       | Переход изделия| V, f, ap, стойкость, стоимость инструмента      |
| 5       | Переход CDE    | Кол-во рабочих ходов, глубина резания            |
| 6       | Рабочий ход    | Подача и скорость резания                        |

Текущая реализация охватывает прагматичную кодировку всех 6 уровней в едином пространстве решений.
