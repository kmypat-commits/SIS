# MachOpt-6L

**Machining Optimization — 6 Levels**
Система параметрической и структурной оптимизации технологических процессов механической обработки.

Генерация вариантов маршрута обработки → многокритериальная оптимизация NSGA-II → Парето-фронт → выбор стратегии → экспорт отчёта.

---

## Развёрнутая версия (продакшн)

https://machopt-6l.vercel.app

Backend: FastAPI (Python serverless) + Frontend: React (Vite).

---

## Быстрый старт (локальная разработка)

### 1. Backend (Python/FastAPI)

```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Backend: http://localhost:8000  
Swagger UI: http://localhost:8000/docs

При первом запуске автоматически создаётся SQLite `machopt.db` и заполняется из `data/machopt_mvp_0001.json`.

### 2. Frontend (React/Vite)

```powershell
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173

### 3. Тесты

```powershell
cd backend
pytest tests/ -v
```

## Сценарий работы

1. **Проект** — выбрать или создать проект
2. **Оптимизация** → **Рассчитать** → Парето-фронт (4 критерия)
3. **Выбор стратегии** — утилитарная / минимаксная / экспертный приоритет
4. **Экспорт** — JSON / HTML-отчёт

| Критерий | Обозначение | Направление |
|----------|------------|-------------|
| Трудоёмкость | `time_total_min` | minimize |
| Затраты | `cost_total_min` | minimize |
| Погрешность наладки | `setup_error_min` | minimize |
| Риск качества | `quality_risk_min` | minimize |

---

## Уровни оптимизации (6 уровней)

| Уровень | Объект | Задача |
|---------|--------|--------|
| 1 | Маршрут CDE | Структура переходов + припуски |
| 2 | Маршрут изделия | Кол-во операций, станок/оснастка/базирование |
| 3 | Наладка | Определение параметров инструмента/заготовки |
| 4 | Переход изделия | V, f, ap, стойкость, стоимость инструмента |
| 5 | Переход CDE | Кол-во рабочих ходов, глубина резания |
| 6 | Рабочий ход | Подача и скорость резания |

Реализована прагматичная кодировка всех 6 уровней в едином пространстве решений.

## Сравнение с аналогами

| Характеристика | MachOpt-6L | Wang et al. (2024) | Ngnassi et al. (2024) | Zhang et al. (2024) |
|----------------|-----------|-------------------|----------------------|-------------------|
| **Область** | Планирование ТП + параметры резания | IPPS (клапанный завод) | Параметры точения | STEP-NC фрезерование |
| **Метод** | NSGA-II + 3 стратегии выбора | Улучшенный NSGA-II | NSGA-II | IHNN + NSGA-II |
| **Критерии** | 4: время, стоимость, точность, качество | 2: время, стоимость | 3: сила, шероховатость, MRR | 3: энергия, время, стоимость |
| **Кол-во операций** | Многооперационный (до 8) | Многооперационный + scheduling | Одиночный проход | Многооперационный |
| **Станки/оснастка** | Да (выбор станка, приспособления, наладки) | Да (выбор станка) | Нет | Нет |
| **Web UI** | Да (React + FastAPI) | Нет (MATLAB) | Нет | Нет |
| **Деплой** | Vercel (public URL) | Локальный | Локальный | Локальный |
| **Материалы** | 4 группы (сталь, чугун, Al, Ti) | 1 (сталь) | 1 (сталь закалённая) | 1 |

**Ключевое отличие**: большинство работ решают задачу optimизации параметров резания для одной операции/одного перехода. MachOpt-6L покрывает полный цикл: от выбора структуры операций до режимов резания, с интеграцией в веб-приложение.
