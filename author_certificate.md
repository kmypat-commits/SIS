# Реферат

**Тип объекта:** программа для ЭВМ  
**Название:** Информационная система оптимизации процессов механической обработки деталей на металлообрабатывающих станках  
**Способ подачи:** Электронная подача  

**Фамилия, имя, отчество автора (-ов):** ЖЕТЕСОВА ГУЛЬНАРА САНТАЕВНА, Кожанов Мурат Галиаскарович, Жаркевич Ольга Михайловна  
**Дата создания объекта:** 03.11.2025  

## Область применения
Разработка предназначена для предприятий и инженерных служб машиностроительной отрасли, занимается автоматизацией оптимизации технологических процессов механической обработки деталей на металлообрабатывающих станках. Система может использоваться в производственном планировании, технологической подготовке производства, и инженерных расчетах, а также внедрена как инструмент повышения эффективности изготовления деталей.

## Назначение
Информационная система предназначена для автоматизированного формирования, анализа и оптимизации структуры и параметров материальных потоков в производственном процессе обработки деталей. Система повышает технологическую точность, снижает трудоёмкость и сокращает производственные затраты благодаря многокритериальной оценке и выбору оптимальных решений на каждом этапе обработки.

## Функциональные возможности
*   **Построение иерархических моделей обработки:** ИС формирует и хранит структуры производственного процесса: маршрут, переход, рабочий ход.
*   **Многокритериальная оптимизация:** Для каждой альтернативы ИС автоматически рассчитывает показатели трудоёмкости, затрат, точности, качества. Производится выбор оптимальных решений по принципу фронта Парето.
*   **Подбор оптимальных режимов обработки:** ИС определяет рациональные значения основных параметров обработки (скорость, подача, глубина и др.), учитывая технологические и ресурсные ограничения.
*   **Экспорт и сохранение результатов:** ИС формирует таблицы с параметрами всех альтернатив, результаты оптимизации экспортируются для дальнейшего анализа (CSV, PDF, HTML и др.).
*   **Управление данными (Электронная подача):** Работа с исходными, промежуточными и итоговыми данными. Ключевые данные (характеристики детали, CDE-элементы, параметры оборудования, условия обработки) сохраняются и могут быть использованы для повторного анализа или коррекции решения.

## Основные технические характеристики
*   **Языки программирования:** Python (Backend-ядро), JavaScript / React (Frontend-интерфейс).
*   **Архитектура:** модульная (распределённая клиент-серверная архитектура через REST API).
*   **Интерфейс:** web-приложение для технологов и инженеров.
*   **Хранение данных:** реляционная БД (SQLite), импорт/экспорт файлов формата CSV/JSON.
*   **Интеграция:** Возможность интеграции в MES/ERP системы предприятия.
*   **Серверные требования:** Linux, от 4 ГБ ОЗУ, поддержка Docker (при необходимости).

## Языки программирования
**Python 3.11** - современная, надёжная и высокоэкспрессивная версия языка, идеально подходящая для быстрой разработки, реализации математических алгоритмов Парето-оптимизации, интеграции с AI-библиотеками и обработки данных. Дополнительно используется **JavaScript** для создания интерактивного пользовательского web-интерфейса.

## Тип реализующей ЭВМ
*   **Операционная система сервера:** Linux Debian 10 (или любая современная ОС Linux/Windows).
*   **Требования к серверу:** Минимальный объем оперативной памяти, необходимой для развертывания приложения на сервере - 8 Gb.
*   **Требования к клиенту:** Минимальный объем оперативной памяти, необходимой для выполнения приложения на клиентском устройстве или машине - 2 Gb. Для работы приложения необходимо наличие современного веб-браузера (например, Google Chrome, Mozilla Firefox).
